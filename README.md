# Akshara Plotted Developments - Website & CMS

A high-end, interactive showcase website and Admin CMS for **Akshara**, a premier residential plotted development company operating in **Vellore, Chittoor, Tirupati, and Chennai**.

## 🌟 Features

- **Pure Showcase Architecture**: Highlighting DTCP, CMDA, RERA & TUDA approved plotted layouts with clear titles and engineering standards.
- **City Filterable Grid**: Filter completed and upcoming layout projects by city.
- **Interactive Project Modals**: CAD masterplan blueprints, plot dimension ranges, layout highlights, and enquiry forms.
- **Leadership Showcase**: Board of Directors featuring Lokesh, Payani, and Sandeep.
- **Admin Panel CMS**:
  - Secure Login (`admin123`)
  - Visitor Analytics & Traffic Line Charts
  - Projects CRUD Manager
  - Content & Leadership CMS
  - Lead Management & CSV Export
- **Design System**: Pure white (`#FFFFFF`) background, deep black typography (`#0A0A0A`), crisp borders, generous whitespace, and mobile-first responsiveness.

## 🚀 Getting Started

Launch the static server using Node.js:

```bash
node server.js
```

Open `http://localhost:8080` in your web browser.
